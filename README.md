# GAB-work (Global Architecture & Building Work)

> **Build. Work. Connect. Trust.**  
> West Africa's Premier Verified Construction Escrow Marketplace.

---

## 🏢 Overview

**GAB-work** is a professional B2B/B2C construction platform connecting building clients, verified artisans, contractors, and site managers across Ghana, West Africa, and international markets.

### Key Capabilities
- **Secured Milestone Escrow**: Client funds held safely until milestone completion is audited on-site.
- **10% Transparent Commission Model**: Direct fee disclosure prior to digital contract signing.
- **Digital Contracts**: Standardized BTP agreements with milestones, BoQ, and Dispute Arbitration.
- **Daily Site Monitoring**: Responsable de Site logging for daily worker presence, weather conditions, progress %, and evidence photos.
- **5 Multi-Role Dashboards**: Custom interfaces for Client, Worker, Company, Site Manager, and Super Admin.
- **Multilingual Support**: Instant live translation in **English**, **Français**, **Español**, and **Deutsch**.
- **Mobile-First Experience**: Smartphone bottom navigation, responsive drawers, bottom-sheet modals, and touch-optimized actions.

## 🚀 Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Internationalization**: React Context i18n (`en`, `fr`, `es`, `de`)

## 🛠️ Getting Started

```bash
# Clone the repository
git clone https://github.com/NarcisseDedome/gab.git
cd gab

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

---

## 📦 Production Build

```bash
npm run build
npm run start
```
